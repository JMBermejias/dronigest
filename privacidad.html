Política de Privacidad - Dronigest

Última actualización: 30 de julio de 2026

Datos que recopilamos

Dronigest no recopila ni transmite datos personales a servidores externos. Toda la información introducida por el usuario (vuelos, pilotos, equipos, etc.) se almacena exclusivamente en el almacenamiento local del dispositivo (localStorage).

Geolocalización

La aplicación puede solicitar acceso a la ubicación del dispositivo para mostrar la meteorología local y la ciudad actual. Esta información se usa únicamente de forma local y no se envía a ningún servidor externo, excepto las llamadas a:

  • Open-Meteo API (meteorología): se envía la latitud/longitud para obtener datos meteorológicos
  • Nominatim / OpenStreetMap (geocodificación): se envía la latitud/longitud para obtener el nombre de la población
  • ipwho.is (geolocalización por IP): se usa como método alternativo de geolocalización

Servicios de terceros

La aplicación utiliza las siguientes APIs de terceros:

  • Open-Meteo - datos meteorológicos
  • Nominatim / OpenStreetMap - geocodificación inversa
  • ipwho.is - geolocalización por IP

Cookies

La aplicación no utiliza cookies propias ni de terceros.

Seguridad

Al ser una aplicación que funciona mayoritariamente sin conexión y almacena los datos localmente, no se transmiten datos sensibles a través de la red.

Contacto

Para cualquier consulta sobre esta política de privacidad, puedes abrir un issue en el repositorio del proyecto.

Cambios en la política

Nos reservamos el derecho de actualizar esta política de privacidad en cualquier momento. Los cambios se publicarán en esta misma página.
